Sentier · sentier-app

Mettre Sentier en ligne, puis le rendre tien

Deux parcours courts : d'abord faire tourner Sentier pour de vrai (GitHub → Supabase → Vercel), puis l'adapter à ta marque — couleurs, logo, nom — sans toucher à la logique de l'app.

Partie 1

Installation

À la fin de cette partie, Sentier tourne sur une vraie URL, avec une vraie base de données, accessible à toi et à tes apprenants.

1

Récupérer ta propre copie du projet

Sentier est distribué comme template GitHub : github.com/mariecreativestrategist/sentier. Sur la page du dépôt, clique Use this template → Create a new repository, donne-lui un nom, choisis Public ou Privé, valide.

Tu obtiens une copie indépendante du code sur ton propre compte GitHub — aucun lien avec l'original, aucun accès partagé, prête à être personnalisée et déployée.

💡 Vercel se branchera sur ce nouveau dépôt (le tien) à l'étape 5 — chaque futur git push dessus redéploiera automatiquement.
2

Créer le projet Supabase

Sur supabase.com, crée un compte puis un nouveau projet (gratuit). Choisis un mot de passe de base de données et note-le de côté.

Une fois créé, va dans Project Settings → API et garde ces trois valeurs sous la main :

Project URL
→ NEXT_PUBLIC_SUPABASE_URL
anon public
→ NEXT_PUBLIC_SUPABASE_ANON_KEY
service_role
→ SUPABASE_SERVICE_ROLE_KEY (secrète, jamais dans le navigateur)
3

Créer les tables

Dans le dashboard Supabase : SQL Editor → New query. Ouvre supabase/migrations/0001_init.sql, colle tout son contenu, clique Run.

Ça crée toutes les tables, les règles de sécurité (un apprenant ne voit jamais les données d'un autre apprenant) et le espace de stockage pour les fichiers.

4

Tester en local avec des données de démo

# dans sentier-app/
cp .env.local.example .env.local
# colle les 3 valeurs de l'étape 2 dans .env.local
npm install
npm run seed
npm run dev

npm run seed crée un compte formateur et 5 apprenants de démonstration avec du contenu réaliste. Mot de passe pour tous : sentier2026 — coach@sentier.app pour l'espace formateur.

5

Déployer sur Vercel

Sur vercel.com/new, connecte ton compte GitHub si ce n'est pas déjà fait, puis importe le dépôt que tu as créé à l'étape 1 (ta copie, pas l'original). Vercel détecte Next.js automatiquement — avant de cliquer Deploy, ouvre Environment Variables et ajoute :

NEXT_PUBLIC_SUPABASE_URL
la même valeur qu'en local
NEXT_PUBLIC_SUPABASE_ANON_KEY
la même valeur qu'en local
🔒 Ne mets pas SUPABASE_SERVICE_ROLE_KEY sur Vercel — elle ne sert qu'au script de seed, exécuté depuis ta machine.

Clique Deploy. Sentier est en ligne sur une URL *.vercel.app en 1 à 2 minutes.

6

Domaine personnalisé (facultatif)

Dans le projet Vercel : Settings → Domains, ajoute ton propre domaine (ex. espace.thecreativestrategist.com) et suis les instructions DNS affichées.

Partie 2

Personnalisation

Ce que tu peux changer depuis l'app (aucun code) et ce qui se change dans quelques fichiers précis du projet.

1

Nom de l'espace

Directement dans l'app : Paramètres → Espace. Aucun code à toucher.

2

Couleurs

Tout le système de couleurs vit dans src/app/globals.css, dans le bloc :root. Change une valeur, toute l'app se met à jour partout où elle est utilisée.

--primaryboutons, liens, progression
--sidebar-bgfond de la barre latérale
--successstatuts validés, payés
--dangeralertes, échecs de paiement
--bgfond général de l'app
--text-primarytitres, texte de lecture
🎨 Pour une nouvelle marque, changer --primary et --sidebar-bg suffit à transformer l'ambiance de toute l'app.
3

Logo

Le rond « S » de la sidebar et de la page de connexion est du texte, pas une image — remplace-le par ton logo dans src/components/shell/app-shell.tsx et src/app/login/page.tsx. L'icône d'onglet se change en remplaçant src/app/favicon.ico.

4

Typographie

Inter (texte courant) et IBM Plex Mono (dates, montants) sont chargées dans src/app/layout.tsx via next/font/google — n'importe quelle police Google Fonts peut les remplacer en changeant les deux imports.

5

Formations, modules, apprenants

Tout le contenu pédagogique se crée depuis l'espace formateur lui-même — aucun accès au code nécessaire au quotidien : Formations → + Nouvelle formation, puis modules, chapitres, exercices et quiz depuis chaque fiche.

6

Pour aller plus loin

Pour toute modification plus structurelle (nouvel écran, nouvelle règle métier), le plus simple reste de redemander à Claude Code en pointant vers ce projet — il connaît déjà la structure : schéma dans supabase/migrations/, logique de chaque section dans son propre actions.ts, composants partagés dans src/components/ui/.
